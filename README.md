## 🚀 Featured Project

### 🌤️ Sky: CotL Height Tool (光遇身高查看工具 · Sky cotl height tool)

A free, privacy-first web tool for **Sky: Children of the Light** players to check and simulate their in-game avatar height using the Outfit QR Code.

*Alat gratis berbasis browser untuk pemain **Sky: Children of the Light** (Sky CotL) guna memeriksa tinggi badan karakter di dalam game melalui QR Code Outfit. Semua diproses di browser — tanpa server, tanpa unggahan data.*

| | |
|---|---|
| 🌍 **Languages** | 繁體中文 · English · 日本語 · Bahasa Indonesia |
| 🌙 **Dark mode** | Toggle tema |
| 📊 **Resize spell simulator** | Simulasi tinggi baru secara acak |
| 🖼️ **Share image maker** | Kustomisasi latar, nama, warna |
| 🔒 **Privacy** | 100% client-side, no data uploaded |
